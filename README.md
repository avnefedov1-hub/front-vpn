# UGSE VPN — демо / demo

**RU.** Публичная демо-версия с вымышленными слотами. Общий ключ `dummy-test-key` открывает все десять слотов, а ключи `dummy-user01` … `dummy-user10` открывают каждый только свой слот. Адреса из тестовой сети 203.0.113.0/24. Настоящий сервис остаётся закрытым.

**EN.** Public demo with fake slots. The shared key `dummy-test-key` opens all ten slots, and `dummy-user01` through `dummy-user10` each open only their own slot. Addresses are from the 203.0.113.0/24 test net. The real service stays private.
